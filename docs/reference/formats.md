# Архивы, XDB и кодировки Heroes V

**PAK, H5U и H5M в исследованной установке читаются как ZIP.** Чтобы переопределить ресурс, сохрани его внутренний путь: для текста версии это `UI/MainMenu2/Version.txt`. Дополнительная папка внутри архива изменит этот путь.

| Формат | Что подтверждено в нашей установке | Как проверять |
|---|---|---|
| `.pak` | Восемь архивов data прочитаны стандартным ZIP-ридером | Посмотреть список членов, дату, размер и байты ресурса |
| `.h5u` | Отдельный ZIP в UserMODs переопределил текст версии; откат убрал метку | Контроль «до → после → после удаления» с перезапуском |
| `.h5m` | Тестовая карта собрана как ZIP с map.xdb, Terrain и Script-ресурсами | Список членов и корректность ссылок; загрузка проверяется отдельно |
| `.xdb` / `.xml` | XML-описания объектов, существ и UI | XML-парсер проверяет синтаксис; это не проверка игровых ссылок |
| `.txt` | Исследованные игровые UI-тексты используют UTF-16LE с BOM | Проверить первые байты и декодирование исходного члена |
| `.lua` | Исследованный combat-startup.lua обрабатывается как UTF-8 | Проверять в соответствующем игровом контексте |
| `.dll` | Исполняемый x86-код | PE-заголовки/экспорты/вызовы; упаковка в H5U не загружает DLL |

## Прочитать ресурс без распаковки всей игры

Python 3, запуск из каталога игры; код ничего не устанавливает:

```python
from zipfile import ZipFile

with ZipFile('data/Universe_mod.pak') as archive:
    name = 'UI/MainMenu2/Version.txt'
    member = archive.getinfo(name)
    raw = archive.read(name)
    print(member.date_time, len(raw), raw[:2].hex())
    print(raw.decode('utf-16'))
```

Для этого проверенного текста BOM — `fffe`. Не применять такое декодирование ко всем файлам подряд: XML учитывает собственную декларацию/BOM, а бинарные члены должны оставаться байтами.

## Составить отчёт по архивам

Для полного сравнения используй `inspect_universe.py` из исходников [xkit](https://github.com/Xaaalera/heroes5-mod-devkit). Нужны Python 3.10+ и установленная исследованная сборка; дополнительных Python-пакетов нет. Игра не изменяется, результаты записываются отдельно.

В PowerShell из каталога исходников xkit задай два своих пути:

```powershell
$env:H5_GAME_DIR = (Resolve-Path '../HeroesV').Path
$env:H5_WORKSPACE = Join-Path (Get-Location).Path '../HeroesV-research'
New-Item -ItemType Directory -Force -Path $env:H5_WORKSPACE
python -X utf8 inspect_universe.py
```

Замени примеры путями своей игры и отдельной папки исследования. Анализатор ожидает базовые `data.pak`, `a2p1-data.pak`, `texts.pak`, `a2p1-texts.pak`, а также `Universe_mod.pak` и `universe_mod_texts_ru.pak`. Другая установка может потребовать изменения анализатора.

| Файл в папке исследования | Содержимое |
|---|---|
| `research/inventory.json` | Число ресурсов, типы файлов, SHA-256 игровых DLL и EXE, состояние отчёта |
| `research/archive-diff.csv` | Ресурсы Universe: добавлены, изменены или совпадают с выбранной базой |
| `research/unpacked/` | XDB, XML, Lua и TXT из Universe и соответствующие базовые файлы, нормализованные в UTF-8 |

Перед запуском JSON получает `status: incomplete`; только завершённый анализ записывает `complete`. При ошибке не используй CSV и распаковку как полный снимок. Устрани указанную причину и повтори запуск. Не запускай два анализа в одну папку одновременно. Старые распакованные файлы не удаляются: для другой сборки выбери новую папку исследования. Эти копии предназначены для чтения, а не установки в игру.

## Ссылка XDB зависит от исходной папки

`href="../Textures/icon.xdb#xpointer(/Texture)"` содержит путь к другому ресурсу и XML-указатель. Если перенести определение в новую папку, относительная ссылка может начать указывать на другой ресурс. При клонировании окна нужно разрешать такие ссылки относительно **старого** расположения, а не просто копировать строку.

В [генераторе клона devkit](https://github.com/Xaaalera/heroes5-mod-devkit/blob/main/scripts/mod-dev.py) также удаляется корневой `ObjectRecordID`: копия не должна выдавать себя за исходный объект. Поддержка конкретного узла проверяется по шаблону; отсутствие узла — ошибка, не повод молча создать похожий.

## Дата ZIP не является полной формулой приоритета

[Анализатор архивов devkit](https://github.com/Xaaalera/heroes5-mod-devkit/blob/main/inspect_universe.py) выбирал более новую дату члена при сравнении совпадающих путей без учёта регистра. Это **правило построения сравнительного отчёта**, не доказанный общий порядок загрузки игры. Карты, UserMODs, loose files и native-патчи требуют отдельного учёта.

Ресурсный маркер доказал один конкретный override. Из него не следует, что алфавитно последний архив всегда побеждает или что ресурс перечитывается без перезапуска.

**Основание:** ZIP-инвентаризация, тесты конвертации/ссылок и живой маркер 21 сентября; [точная сборка](universe-build.md). Нормализованную UTF-8 копию для анализа нельзя бездумно вернуть в пакет вместо исходной кодировки. [Рецепт маркера](../modding/resource-overrides.md).
