# Перед первым модом

Мод должен подходить к конкретной установке Heroes V. Начни с версии игры и требований автора: это полезнее, чем искать универсальную папку для всех модификаций.

## Определи свою установку

Запиши название игры или дополнения, номер патча и уже установленные крупные модификации. Оригинальная Heroes V, дополнения и сборка с Universe — разные условия проверки.

Если автор проверял мод только на своей сборке, это ещё не подтверждает совместимость с твоей.

## Подготовь путь назад

Сохрани копию затрагиваемых файлов и важных сохранений. Держи исходный архив мода: по нему проще понять, что было установлено и что нужно убрать.

Для первых опытов удобна отдельная тестовая копия игры. Не смешивай проверку нового мода с важным прохождением.

## Меняй по одному

Установи один мод и запусти короткий сценарий, где его эффект виден. Если одновременно поставить несколько модификаций, причину ошибки будет сложнее найти.

!!! note "Минимальный контроль"
    Игра запускается, нужное изменение видно, а после удаления мода исходное поведение возвращается.
