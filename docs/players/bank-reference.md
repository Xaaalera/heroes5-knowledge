# Справочник хранилищ


Мод показывает **возможные армии по тирам**, портреты, диапазоны и альтернативы. Фактическую скрытую охрану объекта он не раскрывает.

## Скачать и установить

**[Скачать DLL-пакет 0.1.0-preview.2](https://github.com/Xaaalera/heroes5-bank-reference/releases/download/v0.1.0-preview.2/Heroes5BankReference-0.1.0-preview.2.zip)** — экспериментальный выпуск. Игра запускается привычным способом через Heroes/Lobby; отдельного EXE мода нет. Code → Download ZIP скачивает исходники, а не готовый мод.

[Страница мода на GitHub](https://github.com/Xaaalera/heroes5-bank-reference) · [Universe](https://h5lobby.com/).

Для готового ZIP-пакета нужны Windows и [поддерживаемая игра](../reference/universe-build.md). Python, Git и devkit не нужны.

1. Закрой игру и редактор. DLL-пакет содержит общий `bin/dinput8.dll`, `bin/Heroes5Mods/WorkshopBankReference.dll` и `UserMODs/workshop-army-reference.h5u` для папки установленной игры.
2. Общий `dinput8.dll` нужен один раз для обоих наших модов. Не заменяй одноимённый файл другого мода: совместимость такого сочетания не проверена.
3. Запускай игру как раньше через Heroes/Lobby. Отдельного EXE нашего мода нет.
4. На карте наведи на поддерживаемое хранилище: должна появиться справка по возможным армиям.

Если сохранился старый текстовый прототип `workshop-object-reference.h5u`, убери его из `UserMODs`: он добавляет лишний текст и растягивает карточку. Перед заменой существующего H5U сохрани прежний файл отдельно. DLL справочника и H5U должны быть из одного выпуска. Ограничения проверки приведены ниже.

## Отключение и удаление

Закрой игру. Убери `UserMODs/workshop-army-reference.h5u` и `bin/Heroes5Mods/WorkshopBankReference.dll`. Другие файлы в `UserMODs` не трогай. Общий `bin/dinput8.dll` удаляй только после удаления всех наших DLL-модов и только если он установлен из нашего пакета.

[Разработчикам: сборка и тестовый стенд](../modding/devkit.md#mod-sources).

## Как пользоваться

На карте приключений наведи курсор на поддерживаемое хранилище. В справке отображаются варианты его охраны.

## Как читать справку

[![Склеп: отдельные варианты A и B для каждого тира](../assets/preview/bank-reference-crypt.png)](../assets/preview/bank-reference-crypt.png)

Карточка склепа после удаления старого текстового прототипа. A и B — альтернативы одного тира, а не части одной армии.

- T1/T2… обозначает возможный тир, а не разведанную охрану объекта.
- A/B разделяет альтернативные полные составы; их нельзя суммировать.
- Половинки портрета обозначают заменяющие друг друга виды. Процент применяется к отдельному отряду.
- Число под парой — диапазон всей группы, а не гарантированное количество каждого вида.

[Откуда берутся тиры и диапазоны](../reference/banks.md). Каталог содержит 13 семейств; 19 публичных названий сопоставлены с 12 подтверждёнными типами. Привязка OrcDeposit не найдена; переименованные объекты не поддерживаются выбором по имени.

## Пример: тайник бесов

По публичным данным тайника бесов справочные диапазоны по тирам такие:

| Тир | Диапазон |
|---|---|
| T1 | 90–135 |
| T2 | 120–165 |
| T3 | 150–195 |
| T4 | 180–225 |

Диапазон T2 относится только к этому варианту: он не складывается с другими тирами и не доказывает, что выбранный объект имеет именно T2. [Источник расчёта](../reference/research-diary.md#banks).

## Ограничения

Исторически проверен тайник бесов; 25 сентября при автоматическом DLL-подключении проверена карточка склепа в кадре 1264×921. Обе DLL работали одновременно, включая пять циклов предиктора. Остальные хранилища, размеры экрана и все сочетания функций полностью не проверены.
