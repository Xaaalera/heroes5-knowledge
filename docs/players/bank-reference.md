# Справочник хранилищ


Мод показывает **возможные армии по тирам**, портреты, диапазоны и альтернативы. Фактическую скрытую охрану объекта он не раскрывает.

## Скачать и установить

**Пакет `0.1.0-preview.1` подготовлен, но пока не опубликован:** проверка нового запуска в игре ещё не завершена. Code → Download ZIP скачивает исходники, а не пакет мода.

[Страница мода на GitHub](https://github.com/Xaaalera/heroes5-bank-reference) · [Universe](https://h5lobby.com/).

Для готового ZIP-пакета нужны Windows и [поддерживаемая игра](../reference/universe-build.md). Python, Git и devkit не нужны.

1. Закрой игру и редактор. Распакуй папку `Heroes5BankReference` рядом с игровой папкой `bin`.
2. Открой `workshop_bank_reference.exe` двойным щелчком. Файл `workshop-army-reference.h5u` должен оставаться рядом с ним.
3. Если появится выбор файла, укажи `bin/H5_Game.exe` своей установки Universe. Отмена ничего не устанавливает и не запускает.
4. Загрузчик проверит версию, скопирует свой H5U в `UserMODs` и откроет игру. На карте наведи на поддерживаемое хранилище: должна появиться справка по возможным армиям.

Отличающийся `UserMODs/workshop-army-reference.h5u` не перезаписывается. Закрой игру и сохрани прежний файл отдельно перед заменой. При несовпадении версии игры или пары EXE/H5U проверь сборку и распакуй комплект целиком.

## Отключение и удаление

Закрой игру. Удали `UserMODs/workshop-army-reference.h5u` и папку `Heroes5BankReference`. Другие файлы в `UserMODs` не трогай. Обычный игровой EXE запускает игру без селектора справочника.

[Разработчикам: сборка и тестовый стенд](../modding/devkit.md#mod-sources).

## Как пользоваться

На карте приключений наведи курсор на поддерживаемое хранилище. В справке отображаются варианты его охраны.

## Как читать справку

- T1/T2… обозначает возможный тир, а не разведанную охрану объекта.
- A/B разделяет альтернативные полные составы; их нельзя суммировать.
- Половинки портрета обозначают заменяющие друг друга виды. Процент применяется к отдельному отряду.
- Число под парой — диапазон всей группы, а не гарантированное количество каждого вида.

[Откуда берутся тиры и диапазоны](../reference/banks.md). Каталог содержит 13 семейств; 19 публичных названий сопоставлены с 12 подтверждёнными типами. Привязка OrcDeposit не найдена; переименованные объекты не поддерживаются выбором по имени.

## Пример: тайник бесов

По публичным данным тайника бесов справочные диапазоны по тирам такие:

| Тир | Диапазон |
|---|---|
| T1 | 90–135 |
| T2 | 120–165 |
| T3 | 150–195 |
| T4 | 180–225 |

Диапазон T2 относится только к этому варианту: он не складывается с другими тирами и не доказывает, что выбранный объект имеет именно T2. [Источник расчёта](../reference/research-diary.md#banks).

## Ограничения

Проверка в игре подтверждена на тайнике бесов. Другие хранилища и последние изменения оформления проверены не полностью. Совместная работа с предиктором не подтверждена.
