# Установка и откат мода

У разных модов разные способы установки. Инструкция автора для твоей версии игры определяет, куда класть файлы и нужен ли отдельный запуск.

## Сначала посмотри состав

| Что находится в пакете | Что уточнить |
|---|---|
| `.h5u` или `.pak` | Целевую папку, требования к версии и конфликты ресурсов |
| Файлы `.lua` | Где игра должна загружать скрипт и в каком контексте он работает |
| `.dll` и загрузчик | Совместимый исполняемый файл и способ запуска |

Расширение файла само по себе не доказывает совместимость. Полезно прочитать [объяснение форматов](../reference/formats.md).

## Установи по инструкции

1. Закрой игру.
2. Запиши добавляемые и заменяемые файлы.
3. Сделай копии заменяемых файлов.
4. Выполни инструкцию автора и запусти проверочный сценарий.

Не делай вывод о приоритете архивов только по их именам. Если два мода меняют один ресурс, порядок и результат нужно проверить на конкретной сборке.

## Если результат не тот

Верни исходные файлы или убери только добавленные файлы этого мода. Повтори сценарий без изменения. Сравнение «до / после / после отката» помогает отделить проблему мода от состояния игры.

В сообщении об ошибке полезны версия игры, список модов, последовательность действий и снимок результата. Не прикладывай весь каталог установленной игры.
