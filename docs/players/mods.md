# Моды и установка

Два экспериментальных дополнения для **[Heroes V Universe / Heroes V Lobby](https://h5lobby.com/)**. [Сообщество Universe](https://vk.com/h5universe) · [страница разработки](https://boosty.to/verydobro).

| Мод | Что показывает | Доступность | Исходники |
|---|---|---|---|
| [Предиктор расстановки](deployment-preview.md) | Проекции, карточки грейдов и область хода | Готовый архив ещё не опубликован | [GitHub](https://github.com/Xaaalera/heroes5-deployment-preview) |
| [Справочник хранилищ](bank-reference.md) | Возможные армии по тирам, диапазоны и альтернативы | Готовый архив ещё не опубликован | [GitHub](https://github.com/Xaaalera/heroes5-bank-reference) |

## Скачать моды

Публичных архивов для игроков пока нет: подготовленные пакеты ждут проверки нового запуска в игре. Ссылки GitHub в таблице ведут к репозиториям. На страницах модов есть возможности, управление, простая установка и удаление; ссылка на скачивание появится после публикации выпуска.
