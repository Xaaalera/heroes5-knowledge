# Моды и установка

Два экспериментальных дополнения для **[Heroes V Universe / Heroes V Lobby](https://h5lobby.com/)**. [Сообщество Universe](https://vk.com/h5universe) · [страница разработки](https://boosty.to/verydobro).

| Мод | Что показывает | Подключение | Исходники |
|---|---|---|---|
| [Предиктор расстановки](deployment-preview.md) | Проекции, карточки грейдов и область хода | Собранные EXE + DLL, запуск через свой loader | [GitHub](https://github.com/Xaaalera/heroes5-deployment-preview) |
| [Справочник хранилищ](bank-reference.md) | Возможные армии по тирам, диапазоны и альтернативы | H5U + нативный диагностический запуск devkit | [GitHub](https://github.com/Xaaalera/heroes5-bank-reference) |

## Правила установки обоих модов

1. Сверь [поддерживаемую сборку](../reference/universe-build.md). Одинаковая надпись Universe не гарантирует одинаковые файлы. Проверки хешей не отключать.
2. Закрой игру перед установкой, заменой или удалением файлов. Для опытов используй [тестовую копию](../modding/devkit.md).
3. Следуй инструкции выбранного мода. DLL предиктора не загружается из UserMODs; H5U справочника не заменяет его нативный запуск.
4. Проверь результат в игре после установки. Успешная сборка или запись файла не подтверждает видимость окна.
5. Предиктор отключается обычным запуском игрового EXE, справочник удаляется своим rollback. Точные команды — на страницах модов.

Совместная работа обоих модов отдельно не проверена. Сначала проверяй каждый по своей инструкции. Игра, Universe и профили в репозиториях не распространяются.

## Среда разработки

Оба репозитория закрепляют [devkit](https://github.com/Xaaalera/heroes5-mod-devkit) как submodule и указывают проверенную ревизию. Для агентов в каждом есть AGENTS.md, тесты и обязательное ревью перед push. [Как устроен стенд](../modding/devkit.md).
