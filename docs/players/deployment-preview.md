# Предиктор расстановки

Проекция отмечает **предполагаемое место существа и доступную ему область хода**. Она использует известный тип, но не раскрывает скрытую численность и грейд охраны. Это экспериментальный мод для исследованной сборки Universe; универсального релиза пока нет.

## Состояние разработки

После исправления плотного разрежения исследовательская сборка Superadmin прошла новую независимую проверку: **273/273 боя, 762 отряда, десять проходов карт и 16 864 численных значения**. Прогноз сохранялся до Start и сравнивался с полным фактическим составом после него. Результат относится к объявленной серии этой сборки; все армии, уровни, эффекты и арены он не покрывает. [Новая серия и отдельные проверки пакета игрока](../reference/research-diary.md#placement-player-candidate).

В текущем кандидате пакета игрока есть два независимых расчёта: видимый приблизительный прогноз и скрытый полный расчёт для проверки и пояснений. Обычный прогноз сохраняет доступные числовые диапазоны. В проверенных обычных охранах «Разведка» или надетая «Корона всевидящего» позволяют использовать точный исходный состав; готовое разделение на боевые отряды и скрытые грейды в прогноз не поступают. Подхват результата «Быстрой битвы» остаётся в плане.

После Start кнопка **«Расстановка»** открывает одно схематичное поле: синий — прогноз, оранжевый — факт, зелёный — армия героя. Выбери отряд, чтобы увидеть этап размещения, правило, размер и ряды. Пояснение берётся из полного расчёта только после совпадения всего пака с фактом; иначе причина отмечается как неподтверждённая. Если прогноза не было, окно показывает фактическую расстановку. Флажок **«Считать типы нейтралов известными для прогноза»** действует для следующих нападений в этой игре и сохраняет текущий прогноз.

В этой ветке исправлены приоритеты плотного разрежения и привязка диапазонов к отрядам. Обновлённый пакет отдельно прошёл обычный запуск без SDK, смешанный бой с совпадением внутреннего полного расчёта 7/7 и скриптовый бой без видимого приблизительного прогноза с совпадением внутреннего расчёта 2/2. В обоих боях сохранённый полный расчёт остался неизменным после Start, а кнопка разбора появилась автоматически и открыла окно по физическому клику. **Эти функции пока не входят в скачиваемый ниже пакет.**

Проверка запуска выполнялась через игровой EXE без подключённого SDK; для подготовки боёв затем использовались диагностические команды. Это ограниченная проверка кандидата. Она не переносит всю исследовательскую серию на пользовательскую DLL и не подтверждает точность скачиваемого ниже пакета. Максимальное расширение армий, уровней, навыков, артефактов и арен записано в дальнейший план.

В обычной игре проверены проекции до Start, наведение и карточки грейдов, открытие подробного окна и обе его стрелки. После замены кода в работающей игре окно закрыли штатной кнопкой, открыли повторно и снова проверили стрелки. Область хода также имеет отдельные проверки в SDK; ими не объявляется проверенным каждое существо и препятствие. Эти изменения пока не вошли в опубликованный пакет игрока. [Результаты кандидата](../reference/research-diary.md#placement-player-candidate).

## Скачать и установить

**[Скачать DLL-пакет 0.1.0-preview.2](https://github.com/Xaaalera/heroes5-deployment-preview/releases/download/v0.1.0-preview.2/Heroes5DeploymentPreview-0.1.0-preview.2.zip)** — экспериментальный выпуск. Игра запускается привычным способом через Heroes/Lobby; отдельного EXE мода нет. Code → Download ZIP скачивает исходники, а не готовый мод.

[Страница мода на GitHub](https://github.com/Xaaalera/heroes5-deployment-preview) · [Universe](https://h5lobby.com/).

Для готового ZIP-пакета нужны Windows и поддерживаемая игра. Python, Git и компилятор не нужны.

1. Закрой игру.
2. Общий `dinput8.dll` нужен один раз для обоих наших модов. Если этот файл уже установлен другим модом, не перезаписывай его: совместимость такого сочетания не проверена.
3. Распакуй ZIP. Скопируй `bin/Heroes5Mods/WorkshopDeploymentPreview.dll` в одноимённую папку установленной игры; при необходимости создай `Heroes5Mods` внутри `bin`. Если наш общий загрузчик ещё не установлен, скопируй `bin/dinput8.dll` из пакета в `bin` игры. Уже установленный общий загрузчик оставь.
4. Запускай игру как раньше через Heroes/Lobby. Отдельного EXE нашего мода нет.
5. Начни обычный бой: до Start должны появиться проекции противника. Наведение показывает область хода, ПКМ — карточку существа.

При сообщении о неподдерживаемой версии сверь сборку по ссылке ниже. Штатные `d3d9.dll`, `uni.dll` и `um.dll` не заменяются. Результаты проверки и ограничения приведены ниже.

## Отключение и удаление

Закрой игру и убери `bin/Heroes5Mods/WorkshopDeploymentPreview.dll`. Общий `bin/dinput8.dll` удаляй только после удаления всех наших DLL-модов и только если он установлен из нашего пакета. Файлов предиктора в `UserMODs` нет.

[Разработчикам: сборка и тестовый стенд](../modding/devkit.md#mod-sources).

## Совместимость

Мод разработан для [исследованной сборки Universe](../reference/universe-build.md). Проверены загрузка обеих наших DLL и пять циклов боя с карточками и очисткой. Это не проверка всех сочетаний; другие версии игры не подтверждены.

## Управление

| Действие | Результат |
|---|---|
| Наведение | Область хода выбранного справочного типа |
| Первый ПКМ | Полная карточка базового или уже известного грейда |
| Повторный ПКМ, если грейд неизвестен | База → улучшение → альтернативное улучшение → база |
| Двойной ЛКМ | Подробное штатное окно существа |
| Стрелки подробного окна | Переключение доступных вариантов |
| Start | Удаление проекций, карточек и подсветки |

Если грейд известен, карточка показывает его. Фигуры непрозрачные, со слабым тёплым свечением. Дополнительных нижних стрелок в текущем варианте нет.

## Пример: гремлин и его улучшение

[![Базовый гремлин: скорость 3, здоровье 5](../assets/preview/gremlin-base.png)](../assets/preview/gremlin-base.png)

[![Старший гремлин: скорость 5, здоровье 6](../assets/preview/gremlin-upgrade.png)](../assets/preview/gremlin-upgrade.png)

При переключении скорость меняется с **3 на 5**, здоровье — с **5 на 6**. Вместе с карточкой пересчитывается область хода.

Характеристики не зашиты под показанных существ. `Speed`, `Flying` и `CombatSize` читаются из [определения выбранного типа](../reference/creatures.md); название и поля карточки формирует штатный descriptor. Тип входит в ключ кэша, поэтому область хода другого грейда не должна оставаться прежней.

## Почему в подробном окне количество «1»

Для справки создаётся одно существо без героя и реального боевого стека. Эта единица **не означает одного противника в охране**. Карточка также не учитывает подтверждённые только в реальном бою эффекты.

## Когда прогноз расходится с боем

Проверки 25 сентября выявили ошибки выбора ветки, spread и порядка отрядов. Локальная DLL уже пробует защитное построение, но на паках генератора результат нестабилен: один обычный проход RMG-A совпал по клеткам в 9 из18 смешанных боёв. Текущий скачиваемый preview.2 этих локальных исправлений не содержит. Разделение одиночного пака считается отдельным объяснённым промахом; грейд не штрафуется при сравнении клеток. [Данные и ограничения](../reference/research-diary.md#rmg-placement-check).

Прототип предполагает один отряд на публично известный тип. Игра может разделить его, изменить состав или выбрать специальную стратегию.

В проверенном примере одна проекция крестьянина перед Start превратилась в **три боевых отряда по 10**. Причина расхождения — разделение, а не размер клетки. [Как сама игра строит армию](army-placement.md).

В проверке DLL-подключения 25 сентября на смешанном паке совпала **1 из 7 позиций**, а один одиночный прогноз стал двумя отрядами. Успешная загрузка мода не означает точности расстановки. [Данные этого прогона](../assets/preview/dll-checks-2026-09-25.json).

**Проверки 21–23 сентября 2026:** пользователь подтвердил открытие и переключение реальным ПКМ. Удержание ПКМ отдельно не подтверждено; фоновые сообщения окна не заменяют эту проверку. Скрытые количества, окончательные грейды и готовая боевая армия во входы прогноза не читаются.
