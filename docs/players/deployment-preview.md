# Предиктор расстановки

Проекция отмечает **предполагаемое место существа и доступную ему область хода**. Она использует известный тип, но не раскрывает скрытую численность и грейд охраны. Это экспериментальный мод для исследованной сборки Universe; универсального релиза пока нет.

## Скачать и установить

**Готовый архив для игроков пока не опубликован.** На GitHub доступны исходники; кнопка Code → Download ZIP скачивает код, а не установленный мод.

[Страница мода на GitHub](https://github.com/Xaaalera/heroes5-deployment-preview) · [Universe](https://h5lobby.com/).

Простая установка ещё не оформлена в публичный выпуск. Не требуется собирать мод самостоятельно, чтобы пользоваться этой базой. Инструкции сборки относятся к [разработчикам](../modding/devkit.md#mod-sources).

## Совместимость

Мод разработан для [исследованной сборки Universe](../reference/universe-build.md). Работа на других версиях и совместно со справочником хранилищ не подтверждена.

## Управление

| Действие | Результат |
|---|---|
| Наведение | Область хода выбранного справочного типа |
| Первый ПКМ | Полная карточка базового или уже известного грейда |
| Повторный ПКМ, если грейд неизвестен | База → улучшение → альтернативное улучшение → база |
| Двойной ЛКМ | Подробное штатное окно существа |
| Стрелки подробного окна | Переключение доступных вариантов |
| Start | Удаление проекций, карточек и подсветки |

Если грейд известен, карточка показывает его. Фигуры непрозрачные, со слабым тёплым свечением. Дополнительных нижних стрелок в текущем варианте нет.

## Пример: гремлин и его улучшение

[![Базовый гремлин: скорость 3, здоровье 5](../assets/preview/gremlin-base.png)](../assets/preview/gremlin-base.png)

[![Старший гремлин: скорость 5, здоровье 6](../assets/preview/gremlin-upgrade.png)](../assets/preview/gremlin-upgrade.png)

При переключении скорость меняется с **3 на 5**, здоровье — с **5 на 6**. Вместе с карточкой пересчитывается область хода.

Характеристики не зашиты под показанных существ. `Speed`, `Flying` и `CombatSize` читаются из [определения выбранного типа](../reference/creatures.md); название и поля карточки формирует штатный descriptor. Тип входит в ключ кэша, поэтому область хода другого грейда не должна оставаться прежней.

## Почему в подробном окне количество «1»

Для справки создаётся одно существо без героя и реального боевого стека. Эта единица **не означает одного противника в охране**. Карточка также не учитывает подтверждённые только в реальном бою эффекты.

## Когда прогноз расходится с боем

Прототип предполагает один отряд на публично известный тип. Игра может разделить его, изменить состав или выбрать специальную стратегию.

В проверенном примере одна проекция крестьянина перед Start превратилась в **три боевых отряда по 10**. Причина расхождения — разделение, а не размер клетки. [Как сама игра строит армию](army-placement.md).

**Проверки 21–23 сентября 2026:** пользователь подтвердил открытие и переключение реальным ПКМ. Удержание ПКМ отдельно не подтверждено; фоновые сообщения окна не заменяют эту проверку. Скрытые количества, окончательные грейды и готовая боевая армия во входы прогноза не читаются.
