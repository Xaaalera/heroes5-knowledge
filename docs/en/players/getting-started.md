# Before your first mod

A mod must fit a particular Heroes V installation. Start with the game version and the author's requirements rather than looking for a universal folder for every modification.

## Identify your installation

Record the game or expansion name, patch version, and major modifications already installed. The original Heroes V, its expansions, and a Universe installation are different test environments.

An author testing a mod on their own installation does not establish compatibility with yours.

## Prepare a way back

Keep copies of affected files and important saves. Retain the original mod archive: it helps identify what was installed and what to remove.

A separate test installation is useful for first experiments. Keep new-mod testing separate from a playthrough you care about.

## Change one thing at a time

Install one mod and run a short scenario where its effect is visible. Installing several modifications together makes failures harder to diagnose.

!!! note "Minimum check"
    The game starts, the intended change is visible, and removing the mod restores the original behavior.
