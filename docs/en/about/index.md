# About the knowledge base

This is Xaaalera’s personal knowledge base about Heroes. Its current focus is Heroes V: modifications, game resources, and research into game behavior.

## Who it is for

**Players:** guides to preparing the game and understanding mods.

**Mod creators:** technical notes, formats, examples, and reproducible checks.

Prepared findings are linked in the [knowledge map](../reference/research-index.md), alongside remaining questions.

## Reading technical notes

A game version is part of a technical fact. A field value, memory address, or callable entry point must not automatically be transferred to another build.

A verified result should state its test conditions. A plausible hypothesis remains a hypothesis.

## How publication works

Articles are Markdown files compiled into a static site. Sources are [on GitHub](https://github.com/Xaaalera/heroes5-knowledge). Direct MediaWiki-style editing is not available yet; proposed changes use GitHub.

Content and presentation are stored separately so the site can evolve and material can be prepared for a future migration if needed.

## Suggest a correction

See [how to contribute](../contributing.md). Small, verifiable improvements are especially helpful.
