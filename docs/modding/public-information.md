# Какие данные можно использовать для прогноза

Справочные характеристики типа, видимый интервал численности и точный скрытый состав — три разных источника. Округление уже прочитанной скрытой численности не превращает её в публичную информацию.

## Практическая граница

| Вход | Что он позволяет | Чего не доказывает |
|---|---|---|
| Портрет в обычной подсказке | Сопоставить известный тип с определением | Число боевых стеков после разделения |
| Видимый диапазон численности | Проверить модель на его границах | Точное количество внутри диапазона |
| Creature XDB | Получить свойства известного типа | Фактический грейд скрытого отряда |
| AG_INFO/DefaultStats банка | Показать варианты охраны | Выбранный тир конкретного банка |
| Позиции в боевом Start | Проверить уже состоявшуюся расстановку | Использовать результат как честный прогноз до боя |

Если портрет неоднозначен, неизвестен или принадлежит другой цели, прогноз должен отказаться от этого входа. В исследованном подключении описание цели связывается с новой сеткой именно команды нападения; старое наведение не считается выбранной целью.

## Почему штатный Danger не стал нашим расчётом

`MonsterTooltip/Danger.(WindowTextView).xdb` связан с текстами ARMY_DANGER_*. Мы нашли представление, но не установили происхождение всех данных штатной оценки. Поэтому её нельзя без проверки назвать оценкой только по доступным игроку входам.

Прототип кнопки «Оценить» принимал клик и показывал диагностический ответ. Это подтвердило обработчик UI, **не** модель победы, потерь или вероятности. Предложение считать нижнюю/верхнюю границы и возвращать «рискованно» осталось планом; готового оценщика боя оно не доказывает.

## Почему OCR не является источником истинных статов

На искусственной картинке распознавалось «Бесы 20–30», но это не замер качества на игровом шрифте. В игре полный OCR читаемой карточки голема однажды вернул только «00.»; распознавание отдельных областей дало название и поля. Значит, отсутствие распознанного слова не доказывает отсутствие карточки, а диапазон 40–32 нужно отклонить, не переставить границы молча.
