# Какие данные можно использовать для прогноза

Прогноз до боя может опираться на **видимые типы существ, показанный диапазон численности и справочные характеристики**. Точный состав скрытой армии в эти входы не входит — даже если после чтения округлить его количество.

## Что известно до боя

| Источник | Что можно получить | Что остаётся неизвестным |
|---|---|---|
| Портрет в подсказке | Тип существа | На сколько боевых отрядов он разделится |
| Видимый диапазон численности | Нижнюю и верхнюю границы для расчёта | Точное количество |
| Creature XDB | Свойства указанного типа | Грейд скрытого отряда |
| AG_INFO/DefaultStats хранилища | Возможные варианты охраны | Выбранный тир конкретного объекта |
| Координаты в боевом Start | Фактическую расстановку для сверки | Это уже результат, а не вход прогноза |

Например, из показанного диапазона можно рассчитать два крайних случая. Выбрать единственное точное количество внутри него без дополнительных данных нельзя.

Вход должен относиться к **цели текущего нападения**. В исследованном подключении описание цели связывается с новой боевой сеткой команды нападения. Старое наведение, неизвестный или неоднозначный портрет для этого не подходят.

## Можно ли использовать штатную оценку опасности

У текста опасности найден ресурс `MonsterTooltip/Danger.(WindowTextView).xdb` и строки `ARMY_DANGER_*`. Но происхождение всех входов этой оценки не установлено: пока неизвестно, использует ли она только сведения, доступные игроку.

Собственный оценщик боя тоже не готов. Кнопка «Оценить» в прототипе лишь принимала клик и выдавала диагностический ответ. Расчёт победы, потерь и ответа «рискованно» по границам диапазона остался планом.

## Как проверять распознанный текст

OCR — распознавание текста с изображения — может пропустить даже читаемую карточку:

- На искусственном примере распознано «Бесы 20–30». Это не проверка игрового шрифта.
- С полной карточки голема одна попытка вернула только «00.». Обработка отдельных областей дала название и поля.
- Диапазон `40–32` нужно отклонить как ошибку, а не молча переставить границы.

Поэтому отсутствие текста в ответе OCR не означает, что карточки нет на экране.
