# Консоль xkit в игре

Консоль позволяет управлять тестовой игрой, смотреть ответы команд и проверять подключённые модули прямо в окне Heroes V. Она появляется в сеансе разработки, который запускает xkit. Готовому моду для игрока эта консоль не требуется.

## Открыть консоль

1. [Установи xkit и создай проект](devkit.md).
2. Запусти тестовую игру командой `xkit start имя-проекта` в терминале Windows.
3. Дождись сообщения о готовности игры и подключения SDK.
4. Нажми **«Логи»** в правой верхней части окна игры. Для ввода выбери вкладку **«Команды»**.

Если кнопки нет, проверь, что игра запущена через `xkit start`, и посмотри сообщения этого терминала. Обычный запуск установленного мода не создаёт сеанс разработки.

## Выполнить первую команду

Введи в нижнее поле:

```text
help
```

Нажми **Ctrl+Enter** или **«Выполнить»**. Ответ появится над полем ввода. Обычный Enter добавляет строку в редакторе команды.

`help` показывает список команд; `help army` — справку о конкретной команде. Выбор подсказки или записи истории заполняет поле, а выполняешь команду ты сам.

В консоли используй короткую команду, например `heroes`. В терминале Windows ей соответствует `xkit game heroes`: открой для неё второе окно терминала, пока первый выполняет `xkit start`. Список героев относится к текущей загруженной карте; используй имя из ответа в командах для героя.

## Подсказки, история и управление панелью

| Действие | Как сделать |
|---|---|
| Открыть варианты дополнения | Нажать Tab или кнопку подсказок |
| Вернуть предыдущую команду | Стрелка вверх или выбор в истории |
| Перейти к более новой записи | Стрелка вниз |
| Очистить вывод команд | Выполнить `clear` |
| Изменить размер панели | Потянуть край или угол окна |
| Скрыть панель и продолжить игру | Нажать **«Вернуться на карту»** |

Tab предлагает команды, параметры, карты, героев и обозначения существ. Список героев обновляется из тестовой игры; если карта ещё загружается, подсказка может появиться не сразу. Скрытие панели сохраняет вывод и историю. Для повторного открытия используй «Логи».

## Найти причину ошибки

На вкладке **«Логи»** выбери уровень сообщений и введи часть нужного текста. INFO показывает обычные события, WARNING — предупреждения, ERROR — ошибки, DEBUG — дополнительные подробности. Фильтр меняет видимость строк; файл журнала сохраняется полностью.

Вкладка **«Модули»** помогает проверить состояние подключений. Команды, отправленные из терминала, также появляются в общем журнале сеанса.

Если команда не выполнилась, прочитай ответ и проверь `help имя-команды`. Для диагностики во втором терминале есть `xkit diagnostics`.

После `map` или `restart` дождись, пока в окне игры появится карта приключений. Затем запроси `heroes`: успешный ответ показывает, что список героев уже доступен. До этого не отправляй команды изменения армии или уровня. Сообщение об отправке загрузки и ответ `status` подтверждают связь с игрой, а не готовность карты. Не повторяй действие вслепую, если его исход непонятен.

## Найти файлы диагностики

В терминале выполни `xkit diagnostics`: команда не запускает игру и показывает пути журналов разработки, последней проверки SDK и монитора сбоев. `xkit diagnostics --json` выдаёт пути для скриптов и IDE. Старый отчёт относится к указанным в нём исходникам; наличие файла не подтверждает исправность текущего сеанса.

Монитор сбоев необязателен. Для его подключения скачай [Microsoft ProcDump](https://learn.microsoft.com/en-us/sysinternals/downloads/procdump), распакуй `procdump.exe` и положи в путь, который показывает `xkit diagnostics`. При следующем `xkit start` или `xkit check` SDK проверит подпись Microsoft и подключит монитор к своей тестовой игре. Обнаружение EXE не означает, что его подпись уже проверена. После сбоя снова запроси диагностику: успешное завершение монитора не отменяет ошибки игры.

При ошибке запуска xkit также пытается сохранить совпавшее событие Windows Application Error по процессу, времени создания и пути игры. Системный журнал может обновляться с задержкой или быть недоступен; отсутствие события не доказывает отсутствие сбоя. Модуль и время события выводятся отдельно от исходной ошибки сеанса; они сами по себе не устанавливают причину сбоя.

## Контролировать место на диске

| Команда в терминале | Назначение |
|---|---|
| `xkit storage status` | Показать подготовленные установки и общий кеш |
| `xkit storage clean --keep 3` | Оставить до трёх установок, сохранить снимки старых и объединить одинаковые большие ресурсы |
| `xkit storage restore ARCHIVE` | Восстановить установку из её сохранённого `retired-game.zip` и общего кеша |
| `xkit storage restore-dump FILE.dmp.gz` | Распаковать архивный дамп для внешнего отладчика |

Перед очисткой закрой игру и редактор. `ARCHIVE` и `FILE.dmp.gz` заменяются путями твоих файлов. Для `--keep` допустимы значения от 0 до 3; если лимит занят, перед восстановлением освободи место. Не удаляй общий кеш вручную: сохранённые снимки ссылаются на его ресурсы.

Чтобы найти `ARCHIVE`, открой `.local/test-state` рабочей папки сохранённой тестовой установки: основной снимок называется `retired-game.zip`, прежние снимки — `retired-game-….zip`. Если рабочая папка неизвестна, выполни `xkit diagnostics`, открой напечатанный журнал событий и найди запись `storage_cleaned`: список `result.retired` содержит пары `game` и `archive`, где `archive` — полный путь снимка. Краткий ответ очистки и `storage status` эти пути не перечисляют.

Большие неизменяемые ресурсы тестовых копий используют [NTFS hard links](https://learn.microsoft.com/en-us/windows/win32/fileio/hard-links-and-junctions) в отдельный кеш, а не в установленную игру. Изменяемые файлы остаются независимыми. Сумма размеров папок в Проводнике может учитывать общие байты несколько раз.

Очистка проверяет принадлежность SDK, сборку и границы путей; неизвестные папки не удаляются. Перед удалением тестовой копии проверяется её снимок. Два последних дампа остаются распакованными, старые сжимаются без потери байтов и сверяются по хешу. Журналы и отчёты сохраняют контекст. Эти команды управляют файлами стенда, а не командами внутри игры.

## Что проверено

Руководство относится к консоли xkit preview.5 в поддерживаемой тестовой сборке Universe. В этой версии проверены семь сценариев интерфейса; отдельные живые проверки подтверждали Ctrl+Enter, историю, Tab, изменение размера и разделение прокрутки журнала и камеры. Это не проверка всех сочетаний клавиш на всех картах.
