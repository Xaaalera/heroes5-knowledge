# Тестовая карта: воспроизводимый бой и проверка движения

[**Скачать WorkshopPolygon.h5m**](../assets/WorkshopPolygon.h5m) — полигон для боёв с нейтралами и сравнения арен в Heroes V Universe. Карта 96 × 96 содержит восемь городов с героями, 12 хранилищ, 16 нейтральных армий и шесть объектов запуска арен.

## Скачать и открыть карту

1. Нужна установленная **Heroes V: Повелители Орды с Universe**. Полигон использовался на [зафиксированной сборке](../reference/universe-build.md); совместимость с другими сборками отдельно не проверена.
2. Закрой игру. Скопируй скачанный файл в папку `Maps` рядом с `bin` и `data` в каталоге игры. Создай `Maps`, если её нет. **H5M не распаковывать.** Если там уже есть `WorkshopPolygon.h5m`, сохрани прежний файл отдельно.
3. Запусти игру и найди **«Полигон Universe / Workshop»** в списке пользовательских карт одиночной игры. Начни новую партию на этой карте; старое сохранение не подхватит заменённый H5M.
4. После загрузки должны быть открыта карта и доступны герои восьми фракций. Для обычного боя подведи героя к одному из нейтралов. Для сравнения арен используй шесть объектов в ряду `y = 7` (координаты ниже — клетки карты приключений, не боевого поля).
5. Чтобы сбросить побеждённые армии и посещённые объекты, начни карту заново. Для удаления закрой игру и убери этот H5M из `Maps`.

| Объекты | Координаты на карте приключений |
|---|---|
| Города | `x = 14, 36, 58, 80`; ряды `y = 17, 41` |
| Нейтралы `pack_0…pack_3` | Те же X; `y = 28` |
| Нейтралы `pack_4…pack_7` | Те же X; `y = 48` |
| Нейтралы `pack_8…pack_11` | Те же X; `y = 51` |
| Нейтралы `pack_12…pack_15` | Те же X; `y = 54` |
| Хранилища | `x = 12, 26, 40, 54, 68, 82`; ряды `y = 60, 72` |
| Арены `arena_1…arena_6` | `x = 10, 25, 40, 55, 70, 85`; `y = 7`, в порядке таблицы сцен ниже |

Сценарные арены вызывают `StartCombat` против 80 крестьян, 35 мечников и 12 священников. Обычные нейтралы используют нападение на объект карты. При старте выдаются 1000 единиц каждого неголдового ресурса и 100000 золота; скрипт периодически пополняет движение героев в пределах обычного дневного лимита. Это полигон, не сбалансированный сценарий для прохождения.

**Что входит в файл:** карта, собственный плоский terrain, тексты и Lua-скрипты. Модели и определения объектов загружаются из установленной игры. DLL предиктора и командный SDK не нужны. Из публичной копии удалены диагностическая подписка `UniverseTrigger` и сбор послебоевых результатов; расположение объектов, армии, terrain и вызовы арен сохранены. Боевой скрипт лишь печатает позиции защитников после Start.

**Проверка выпуска:** структура ZIP/XDB, ссылки внутри карты и отличие от рабочего полигона проверены 24 сентября. На исходном полигоне ранее проверялись движение и бои; эта очищенная копия ещё не прошла отдельный запуск через меню. Не считаем это проверкой всех шести арен. Если карта не появляется в списке, проверь, что файл лежит в `Maps` именно запускаемой установки и браузер не добавил расширение `.zip`.

SHA-256 скачиваемого файла: `b5baf474cb523dfa9ec66831676d9c98c722198f1e8af017290d38ec38fa68dc`.

## Один состав — несколько арен

На нашем полигоне для одинаковой смешанной армии подготовлены:

| Ресурс сцены | Назначение контроля |
|---|---|
| Grass_Big_01 | Большая травяная арена |
| Dirt_Small_01 | Малая земляная |
| Sand_Big_01 | Большая песчаная |
| Snow_01 | Снежная |
| Lava_Small_01 | Малая лавовая |
| River_Grass_Big_01 | Травяная у реки |

Ресурсы искались под `Scenes/CombatArenas/` в data.pak; ссылка на Scenery проверялась отдельно. Наличие шести сценариев в генераторе не означает, что каждый из них прошёл живую проверку. Обычные pack_0…pack_15 дополнительно проверяют путь реального нападения.

Для сравнения фиксируются состав/количества, герой, маска препятствий и координаты Start. Если одновременно поменять состав и поле, разницу результата нельзя приписать только препятствию.

## Если делаешь собственную карту

- Под дорожным `StoneRoad` нужен базовый `Grass`. Без него на раннем полигоне герой не мог нормально ходить, хотя проверка связности клеток проходила.
- `ChangeHeroStat` пополняет движение в пределах дневного максимума. Значение 9999999 в скрипте не означает безлимит: обход ограничения применялся только в отдельном тестовом процессе.
- Меняй H5M после выхода из игры и начинай карту заново. Командный запуск `-advmap` в стенде требовал отдельного исправления; для скачанной карты используй меню.
